# 照相馆模拟经营 · 完整设定文档

版本 1.0 · 核心定位：无限经营 · 现金流驱动 · 无结局

---

## 第一部分：核心系统

### 1.1 游戏定位

| 项目 | 定义 |
|---|---|
| 类型 | 单机模拟经营 |
| 核心约束 | 现金流 |
| 游戏长度 | 无限，玩家自行决定停止 |
| 失败条件 | 破产（现金无法周转） |
| 胜利条件 | 无 |
| 时间系统 | 游戏内时间，可 1x/2x/4x/暂停/跳过 |
| 存档 | 自动存档，随时退出 |

### 1.2 核心循环

```
日报表 → 决策 → 营业 → 结算 → 日报表
```

**一天的结构**

| 时段 | 玩家操作 |
|---|---|
| 早上 | 查看预约、员工状态、现金余额、市场动态 |
| 上午 | 做经营决策：定价、排期、广告、采购、招聘、装修 |
| 白天 | 营业：客人到店、拍摄、化妆、场景、灯光、交付 |
| 晚上 | 结算：收入-固定支出-变动支出=净现金流 |
| 深夜 | 可选：外出采风、修图、加班接单 |

### 1.3 现金流系统

**核心公式**
```
每日净现金流 = 当日收入 - 当日固定支出 - 当日变动支出
现金余额 = 昨日余额 + 今日净现金流
```

**收入项**

| 来源 | 说明 |
|---|---|
| 拍摄费 | 按订单类型和定价 |
| 加印/相框 | 附加销售 |
| 修图费 | 精修单独收费 |
| 化妆费 | 单独或打包 |
| 场景租赁 | 外部团队租用场地 |
| 版权费 | 商业作品授权 |
| 线上收入 | 线上订单、课程、带货 |
| 流量分成 | 平台补贴 |

**固定支出（每天扣除）**

| 项目 | 计算方式 |
|---|---|
| 房租 | 面积 × 地段单价 |
| 物业/水电 | 面积 × 固定系数 |
| 员工基本工资 | 人数 × 岗位工资 |
| 设备折旧 | 设备总值 × 日折旧率 |
| 贷款利息 | 贷款余额 × 日利率 |
| AI 订阅费 | 若使用 AI 工具 |

**变动支出**

| 项目 | 触发条件 |
|---|---|
| 耗材 | 每单消耗相纸、化妆品、道具 |
| 广告费 | 玩家主动投放 |
| 加班费 | 员工加班 |
| 赔偿/退款 | 客诉处理 |
| 维修费 | 设备故障 |
| 清运费 | 拆除装修 |

**现金流状态**

| 状态 | 条件 | 后果 |
|---|---|---|
| 健康 | 现金 > 30 天固定支出 | 可扩张、可贷款 |
| 紧张 | 现金 7~30 天固定支出 | 谨慎决策 |
| 危险 | 现金 < 7 天固定支出 | 警告，员工士气下降 |
| 断裂 | 现金 < 0 | 触发被动收缩 |
| 破产 | 连续 7 天负且无解 | 存档结束 |

### 1.4 时间与节奏

| 速度 | 用途 |
|---|---|
| 暂停 | 做决策、看报表、摆布局 |
| 1x | 微操、吵架、锐评 |
| 2x | 普通营业 |
| 4x | 快速过天 |
| 跳过 | 直接跳到晚上结算 |

**原则**：任何环节都可暂停，任何时刻都可存档退出。

## 第二部分：经营系统

### 2.1 订单系统

**订单类型**

| 类型 | 客单价 | 耗时 | 难度 | 解锁条件 |
|---|---|---|---|---|
| 证件照 | 低 | 短 | 低 | 初始 |
| 标准写真 | 中 | 中 | 中 | 初始 |
| 婚纱 | 高 | 长 | 高 | 新娘妆化妆师 |
| 亲子 | 中 | 长 | 中 | 儿童道具 |
| 宠物 | 中 | 中 | 高 | 宠物安抚道具 |
| 商业产品 | 高 | 中 | 中 | 商业摄影设备 |
| 网红打卡 | 低 | 短 | 低 | 网红场景 |
| 高端定制 | 极高 | 长 | 极高 | 口碑 4 星 + 大师设备 |

**订单流程**
```
咨询 → 报价 → 预约 → 到店 → 化妆 → 场景 → 灯光 → 拍摄 → 选片 → 修图 → 交付 → 售后
```

**排期规则**
- 每天有限时段（如 8 个时段）。
- 每个订单占 1~4 个时段。
- 超时接单 → 客人等待 → 满意度下降。
- 员工数量决定同时可处理的订单数。

### 2.2 定价系统

**定价策略**

| 策略 | 价格系数 | 客流影响 | 口碑影响 |
|---|---|---|---|
| 低价引流 | 0.6x | +50% | - |
| 市场均价 | 1.0x | 基准 | 基准 |
| 中高端 | 1.5x | -30% | + |
| 高端定制 | 2.5x | -60% | ++ |
| 奢侈 | 4.0x | -80% | +++ |

**定价与品牌调性挂钩**：低价做久了，高端客人不来。高端做久了，大众客人不敢进。

### 2.3 广告与线上运营

**广告渠道**

| 渠道 | 成本/天 | 覆盖 | 转化率 | 品牌影响 |
|---|---|---|---|---|
| 社区传单 | 低 | 本地 | 低 | 亲民 |
| 朋友圈 | 低 | 熟人 | 中 | 亲民 |
| 小红书 | 中 | 年轻女性 | 中 | 网红 |
| 抖音 | 中 | 大众 | 高 | 网红 |
| 本地杂志 | 高 | 高端 | 低 | 专业 |
| 异业合作 | 中 | 精准 | 中 | 视对象 |

**线上账号**

| 指标 | 说明 |
|---|---|
| 粉丝数 | 影响自然客流和广告转化 |
| 内容表现 | 每条内容的曝光/互动/涨粉 |
| 发布频率 | 每天可发 1 条 |
| 内容来源 | 相册中的作品 |
| 内容评分 | 作品质量 × 话题度 × 时机 |

**线上→线下转化**
```
线上曝光 → 互动 → 涨粉 → 到店预约 → 线下消费
```
转化率受品牌调性、口碑、距离影响。

### 2.4 员工系统

**岗位**

| 岗位 | 作用 | 工资 |
|---|---|---|
| 摄影师 | 拍摄，决定质量上限 | 高 |
| 化妆师 | 妆造，影响上镜度和满意度 | 中 |
| 修图师 | 后期，影响交付速度和质量 | 中 |
| 客服/销售 | 接单、安抚、追加销售 | 低 |
| 助理 | 打杂，提升效率 | 低 |

**员工属性**

| 属性 | 说明 |
|---|---|
| 技能 | 岗位专业能力，影响产出质量 |
| 速度 | 处理订单的效率 |
| 状态 | 疲劳、士气 |
| 性格 | 影响与客人/同事互动 |
| 忠诚 | 离职风险 |

**员工管理**
- 招聘：花钱，看运气
- 培训：花钱，提升技能
- 排班：决定每天谁上班
- 解雇：赔钱，掉士气
- 加薪：留人，增加固定支出

**员工出错**
- 每多一个员工，每天多一次出错判定。
- 出错类型：迟到、拍废、说错话、丢东西、和客人吵架。
- 出错后果：差评、赔偿、重拍、口碑下降。

### 2.5 场地系统

**网格制**：初始 6×8 格，每格 0.5 米。

**功能分区**

| 区域 | 作用 | 缺失后果 |
|---|---|---|
| 接待区 | 客服、等待、选片 | 客人站着等，满意度掉 |
| 化妆区 | 化妆师工位 | 化妆速度减半 |
| 棚拍区 | 拍摄主场地 | 接不了正经单 |
| 后期区 | 修图工位 | 修图效率低 |
| 储物区 | 放设备道具 | 设备损坏率上升 |
| 展示区 | 挂作品、样品 | 新客信任度低 |

**扩张**

| 方向 | 面积 | 购地费 | 装修费 | 工期 |
|---|---|---|---|---|
| 向右 | +2×8 | 中 | 中 | 2 天 |
| 向后 | +6×3 | 高 | 高 | 3 天 |
| 二楼 | +6×8 | 极高 | 极高 | 5 天 |

**扩张风险**
- 每月固定支出跳涨。
- 施工期间营业效率下降。
- 收入没跟上 → 亏损螺旋。

**收缩**

| 方式 | 触发 | 回收 |
|---|---|---|
| 主动收缩 | 玩家选择 | 投入的 30% |
| 被动收缩 | 现金断裂 | 废品价，装修全损 |

**收缩连锁反应**
- 面积缩 → 工位少 → 接单能力降 → 收入降。
- 支出也降 → 可能反而活下来。
- 客人看到店在缩小 → 差评 + 流失。

**装修**
- 从家具库拖拽到格子。
- 每个物件占 1~4 格。
- 成本：购买费 + 安装费 + 每日维护 + 拆除费。
- 氛围分：家具综合评分，影响客单价、员工效率、锐评好评率。
- 边际递减：堆满奢侈品不如搭配得当。

### 2.6 设备系统

| 类别 | 影响 | 升级效果 |
|---|---|---|
| 机身 | 画质上限 | 解锁高分辨率订单 |
| 镜头 | 焦段/光圈 | 解锁虚化/广角订单 |
| 灯光 | 布光可能性 | 解锁复杂光影订单 |
| 背景 | 场景多样性 | 解锁主题订单 |
| 道具 | 拍摄辅助 | 解锁特殊订单 |
| 修图设备 | 后期效率 | 缩短交付时间 |
| AI 设备 | 自动化 | 降低人工成本，但影响品牌 |

**设备维护**
- 每日折旧。
- 随机故障。
- 维修费随设备价值上升。

## 第三部分：微操系统

### 3.1 拍摄微操

**触发**：亲自拍摄订单时。

**玩法**
- 取景框平移/变焦。
- 构图辅助线（三分线、水平仪）。
- 客人表情变化，有“微笑峰值”窗口。
- 玩家在峰值按快门。
- 评分：构图 + 时机 + 清晰度。

**结果**：照片质量分 → 客人满意度、小费、口碑、复购。

**跳过**：按员工技能自动结算，无额外加成。

### 3.2 灯光微操

**触发**：高价值订单或玩家主动练习。

**玩法**
- 2~4 个光源。
- 每个可调：角度、距离、功率、色温、柔光罩。
- 实时预览光影图。
- 目标：匹配订单要求的光影效果。

**评分**：明暗比、重影、背景分离度。

### 3.3 场景搭建微操

**触发**：高价值订单或玩家主动练习。

**玩法**
- 从道具库拖拽摆放。
- 调整位置/角度。
- 评分：主题契合、构图友好、与灯光协同。

**简化版**：选预设场景 + 微调 1~2 个滑块。

### 3.4 动作指导微操

**触发**：拍摄过程中。

**玩法**
- 客人有隐藏状态：紧张度、疲劳度、信任度。
- 玩家从指令卡中选择话术。
- 不同性格客人吃不同话术。
- 指导成功 → 微笑窗口变长，表情上限提高。

### 3.5 后期修图微操

**触发**：交付前。

**玩法**
- 滑块调整：曝光、色温、对比、磨皮。
- 客人有偏好。
- 过度修图 → 满意度下降。
- 可雇修图师自动处理，但损失“手工感”加成。

### 3.6 外出采风

**触发**：玩家主动选择。

**玩法**
- 随机场景：公园、老街、天台、雨天窗边。
- 有限胶卷（如 12 张）。
- 移动目标：鸟、猫、路人、飘动塑料袋。
- 目标：拍到特定构图。
- 作品进相册，可用于线上内容。

**收益**：技能点、灵感、素材、稀有作品。

## 第四部分：附属系统

### 4.1 吵架系统

**触发**：特定客诉场景。

**玩法**
- 回合制论战，双方气势条。
- 玩家从手牌选择回应。
- 手牌类型：讲事实、讲道理、打感情、耍无赖、认怂。
- 克制关系：不同顾客吃不同套路。

**顾客类型**

| 类型 | 弱点 | 赢了后果 |
|---|---|---|
| 蛮横型 | 讲事实 | 灰溜溜走人 |
| 精明型 | 耍无赖 | 反而尊重你 |
| 情绪型 | 打感情 | 变死忠 |
| 网络型 | 讲道理+证据 | 删帖 |
| 碰瓷型 | 耍无赖对轰 | 拉黑 |
| 权力型 | 讲事实+合同 | 可能丢单 |
| AI质疑型 | 真实价值 | 服气 |

**输赢后果**

| 结果 | 影响 |
|---|---|
| 赢 | 按原价付，口碑+，品牌硬气 |
| 输 | 白嫖/砍价，口碑-，碰瓷客变多 |
| 平 | 打折，口碑不变 |

**限制**
- 同一天最多吵 2 次。
- 吵架消耗时间和精力。
- 赢太多 → 品牌变凶 → 温柔客群流失。

### 4.2 锐评系统

**触发**：游戏内每周三晚。

**玩法**
- 玩家从相册选 1 张投稿。
- 锐评师点评。
- 结果分五档：封神、好评、有梗、毒舌、无人问津。

**锐评师类型**

| 类型 | 风格 | 受众 |
|---|---|---|
| 毒舌老法师 | 专业刻薄 | 同行 |
| 抽象艺术人 | 高深莫测 | 艺术圈 |
| 沙雕网友 | 纯搞笑 | 大众 |
| 温柔鼓励型 | 少见好评 | 全客群 |
| 神秘AI评审 | 冷冰冰数据 | 极客 |

**结果影响**

| 档位 | 粉丝 | 口碑 | 技能点 |
|---|---|---|---|
| 封神 | +++ | ++ | + |
| 好评 | ++ | + | + |
| 有梗 | ++++ | - | ++ |
| 毒舌 | ++ | -- | ++ |
| 无人问津 | 0 | 0 | 0 |

**联动**
- 客片被锐评 → 客人看到 → 复购或投诉。
- 爆梗作品 → 可印成海报、做周边。
- 锐评被骂 → 可回怼 → 触发吵架。

### 4.3 客服与售后

**客服事件（弹窗）**

| 事件 | 选项 | 影响 |
|---|---|---|
| 客人说照片显胖 | 免费重拍/部分退款/解释 | 金钱、口碑、客人情绪 |
| 要求加急 | 加钱/拒绝/加班 | 金钱、员工士气 |
| 要求免费加修 | 同意/拒绝/协商 | 口碑、利润 |
| 差评威胁 | 妥协/硬刚/协商 | 口碑、品牌 |
| 改期 | 同意/拒绝/收费 | 排期、满意度 |

**售后**
- 重拍：消耗时间、耗材。
- 退款：直接损失。
- 加急：员工加班，士气下降。
- 修图返工：修图师时间占用。

### 4.4 品牌调性

**调性由行为累积决定**

| 调性 | 特征 | 客群 | 定价上限 |
|---|---|---|---|
| 亲民 | 便宜、快、热闹 | 大众 | 低 |
| 专业 | 设备好、流程严 | 同行/高端 | 高 |
| 艺术 | 氛围强、慢 | 藏家/文艺 | 极高 |
| 网红 | 打卡点、出片 | 年轻人 | 中 |
| 硬气 | 不妥协、有原则 | 讲理的高端客 | 高 |

**调性影响**
- 定价上限。
- 广告渠道效果。
- 锐评师态度。
- 吵架时谁站你。
- 员工招聘难度。

## 第五部分：市场环境

### 5.1 AI 冲击

**AI 能力时间线**

| 阶段 | AI 能做什么 | 市场影响 |
|---|---|---|
| 萌芽 | 证件照、简单修图 | 证件照利润减半 |
| 冲击 | 标准写真、换脸 | 中端写真订单 -30% |
| 碾压 | 婚纱、全家福 | 传统婚纱店倒闭 |
| 逼宫 | 艺术摄影 | 高端市场动摇 |
| 共存 | 接近专业 | 玩家选择路线 |

**AI 成本**
- 订阅费、算力费、版权费。
- 用 AI 的店，单张成本低，但每月固定支出高。

**AI 短板（玩家可打）**

| 短板 | 玩家打法 |
|---|---|
| 没有真实情感 | 拍真实瞬间 |
| 没有现场 | 卖体验 |
| 没有实体 | 做相册、相框 |
| 没有信任 | 做老客、社区 |
| 没有故事 | 每张照片有故事 |
| 不会吵架 | 吵架赢 AI 店 |
| 不懂本地 | 做本地人情网络 |
| 有 AI 味 | 锐评师和客人反感 |

**玩家应对路线**

| 路线 | 短期 | 中期 | 长期 |
|---|---|---|---|
| 纯低价 | 有单 | 被卷死 | 必输 |
| 纯手工 | 单少但精 | 客群窄但稳 | 小但活 |
| 纯 AI | 效率高 | 利润薄 | 被更便宜 AI 卷 |
| 真人+AI | 成本高 | 质量高 | 建立壁垒 |
| 转型体验 | 收入降 | 新客群 | 不可替代 |

**进化值 vs AI 替代能力**
- 玩家行为累积“不可替代度”。
- AI 随时间提升“替代能力”。
- 不可替代度 > 替代能力 → 活得好。
- 不可替代度 < 替代能力 → 被卷。

### 5.2 竞争对手

**AI 照相馆**
- 价格砍半。
- 出片快。
- 没有真实体验。
- 可以探店、攻击、合作。

**传统照相馆**
- 老牌，口碑稳。
- 设备旧，创新慢。
- 可能挖你员工。

**网红工作室**
- 线上强，线下弱。
- 流量大，交付差。
- 可能抄袭你风格。

### 8.1 主界面

现金余额：3,450

### 8.3 反馈原则

- 所有数值变化即时可见。

- 客人满意度用星级。
- 线上数据用图表。
- 事件用弹窗，必须处理才能继续。
