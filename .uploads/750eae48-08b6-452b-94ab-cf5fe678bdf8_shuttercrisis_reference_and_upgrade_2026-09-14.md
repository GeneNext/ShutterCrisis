## 二、升级系统优化（核心问题 + 杠杆）

### 核心诊断
你们的 sink 有 6 类：设施等级 / 空间形态 / 地图推进 / 员工进阶 / AI订阅 / 广告。
最大隐患：**设施升级的收益被埋进一个不透明的总池**。
`qualityCeiling = 0.3 + (camera+lens+light+backdrop)*0.045 + studioForm*0.06` —— 四路线设备全倒进同一个天花板数字。
玩家看不出"L3 机身"和"L3 灯光"各买了什么。这正是你们在双点医院 F2 里点名的"收益不透明→唯一解 build"陷阱，你们预测到了，但原型还没解。
好消息：你们已有正确范式——`s.fac.reception >= 2 → clarity +0.1`、`forms.reception >= 1 → +0.08`。**把这种"每级一个具名效果"推广到全部设施**。

### 杠杆 A — 设施升级：从"数值池"拆成"订单解锁"
- 现状：设备只抬 qualityCeiling（软上限）。
- 改法：每个设备 tier 给一个**具名能力**（新订单类型 / 新定价头部空间 / 新锐评受众），天花板只作次要软封顶。
  - camera L2 解锁"海报/高分辨率输出"（单值↑）
  - camera L3 / light L3 解锁 商业产品 tier（目前仅 light L3 + grade3 卡）
  - lens L3 解锁"虚化写真"子单（高毛利）
  - light L4 解锁"高调商业光"→ product/corp 满意度+
- 玩家决策：每次购买 = "现在我能接这类活了"的可见 agency，而非 +0.045。
- [PLACEHOLDER] 各 tier 解锁阈值与对应订单毛利需 playtest，假设单店中期日流水目标 ¥8,000（见 MAP 商圈任务），解锁带来的增量应使该目标在 14 天内可达。

### 杠杆 B — 空间形态：从"容量+"升级成"体验区/定位"
- 现状：`FORM_RENOVATE` 只给 capBonus + cost/days，形态只有风味名。
- 改法：每个形态 tier 改变**哪类客群舒服**与**哪类订单有质量/满意度乘子**
  - 独立化妆室(form1) → 婚纱/亲子 满意度 +0.1（隐私敏感）
  - VIP接待室(form2) → star/corp 客 溢价 +20% 且等待 0
- 效果：昂贵的形态改造变成"你想服务谁"的定位决策，回扣 品牌调性（目前品牌只被定价档推动，来源太窄）。

### 杠杆 C — 地图推进：每地点改"决策"而非只改 priceMul
- 现状：MAP 地点差异主要在 priceMul + orderBoost，迟早沦为他们自己点名的"换皮流水线"。
- 改法：每地点加一个**结构约束或新动词**
  - 老街：禁 AI（纯度加成）/ 手工慢工
  - 大学城：内容 virality 乘子，但毛利低
  - 商圈：企业合规（需资质/合同子系统）
  - 影视基地：团队规模门槛（需 N 名大师）
  - 时装周：指名客（关系/口碑门控）
- 让 5 地点逼出 5 种不同 build，而不是同一个循环的价目表滑杆。

### 杠杆 D — 员工进阶：把"资格"做成与店铺等级平行的解锁轴
- 现状：`STAGES` 用 skill+qual 卡，但 高端定制 同时被 grade4 卡 → 员工与等级重叠，成长只有一条轴。
- 改法：让**大师资格独立解锁订单类型**（有大师摄影师 + 设备达标，3★ 也能接 高端定制）。制造经典管理抉择："买机器 vs 雇专家"两条并行成长线在订单上交汇。

### 杠杆 E — 定价/品牌：你们已做对，别破坏，再补牙
- 已对：`pr.flow` 1.5→0.2 真实影响客流；品牌由行为累积。这避开了双点医院"定价形同虚设"差评。
- 补：让 品牌调性 有机械牙齿——专业调性自然带来 corp 客流、艺术调性提升 锐评封神概率。目前品牌偏装饰。

### 杠杆 F — 破产防线：把"危险态"变成"推荐动作"
- 现状：现金流四态 + 红脉冲 + 救命大单。可读性已赢。
- 补：现金 < 7 天固定支出时，自动浮出"可砍广告/可降设备折旧/可接救命单"的具体选项（你们的晨会/复盘计划落点），而非只闪红。CS 叠加层思路。

### 杠杆 G — 锐评回灌
- 现状：锐评给 fans/rep/skill，不解锁订单。
- 改法：封神 → 解锁"指名复购客"；毒舌翻车 → 触发客诉事件（已有联动设计但未接订单层）。让"出片质量"成为长期成长钩子。

## 三、给你们的下一步（诚实的方法论提醒）
1. Tier A 四作按你们自己的"五件套"工作规则做深采（功能栈表+数值表+差评专项+置信度+转验收），再决定是否采纳——不要凭本文件直接落地。
2. 升级优化从**杠杆 A** 起步：它改动最小（只在 catalogs 里给每级加一个具名效果字段）、风险最低、且直接修掉你们自己预言的"唯一解 build"陷阱。
3. 无脑最优解测试（V2 §1.4 硬规则4）必须覆盖新加的"形态/资格解锁"，否则会造出新的唯一解。
