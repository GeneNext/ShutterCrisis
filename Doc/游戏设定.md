# 《营业！快门危机》游戏设定

> 本文件是本项目的**玩法设计基线**（源自立项文档 `设定.txt`，版本 1.0）。
> 数值与规则以本文件为准；**代码实现与它们的对应关系**见 [`玩法实现.md`](玩法实现.md)。
> 本文件只写"规则是什么"，不写"怎么实现"——实现会变，规则要稳。

---

## 一、游戏定位

| 项目 | 定义 |
|---|---|
| 中文名 | 营业！快门危机 |
| 英文名 / 工程名 | ShutterCrisis |
| 类型 | 单机模拟经营 |
| 核心约束 | **现金流**——唯一会把游戏结束的资源 |
| 游戏长度 | 无限，玩家自行决定何时收店 |
| 失败条件 | 破产（现金断裂且连续 7 天净现金流为负） |
| 胜利条件 | **无**（本作不设胜利条件，也不设"通关"） |
| 时间系统 | 游戏内以"天"为单位；1 回合 = 1 游戏日，天数由玩家点「结束营业」推进 |
| 存档 | 服务器权威，自动存档，随时退出 |

### 1.1 核心循环

```
日报表 → 决策 → 营业 → 结算 → 日报表
```

| 时段 | 玩家操作 |
|---|---|
| 早上 | 查看预约、员工状态、现金余额、市场动态 |
| 上午 | 做经营决策：定价、排期、广告、采购、招聘、装修 |
| 白天 | 营业：客人到店、拍摄、化妆、场景、灯光、交付 |
| 晚上 | 结算：收入 − 固定支出 − 变动支出 = 净现金流 |
| 深夜 | 可选：外出采风、修图、加班接单 |

## 二、现金流系统（核心）

```
每日净现金流 = 当日收入 − 当日固定支出 − 当日变动支出
现金余额     = 昨日余额 + 今日净现金流
```

### 2.1 收入项

| 来源 | 说明 |
|---|---|
| 拍摄费 | 按订单类型和定价 |
| 加印 / 相框 | 附加销售 |
| 修图费 | 精修单独收费 |
| 化妆费 | 单独或打包 |
| 场景租赁 | 外部团队租用场地 |
| 版权费 | 商业作品授权 |
| 线上收入 | 线上订单、课程、带货 |
| 流量分成 | 平台补贴 |

### 2.2 固定支出（每天扣除）

| 项目 | 计算方式 |
|---|---|
| 房租 | 面积 × 地段单价 |
| 物业 / 水电 | 面积 × 固定系数 |
| 员工基本工资 | 人数 × 岗位工资 |
| 设备折旧 | 设备总值 × 日折旧率 |
| 贷款利息 | 贷款余额 × 日利率（本版本不做贷款） |
| AI 订阅费 | 若使用 AI 工具 |

### 2.3 变动支出

| 项目 | 触发条件 |
|---|---|
| 耗材 | 每单消耗相纸、化妆品、道具 |
| 广告费 | 玩家主动投放 |
| 加班费 | 员工加班 |
| 赔偿 / 退款 | 客诉处理 |
| 维修费 | 设备故障 |
| 清运费 | 拆除装修 |

### 2.4 现金流状态

| 状态 | 条件 | 后果 |
|---|---|---|
| 健康 | 现金 > 30 天固定支出 | 可扩张 |
| 紧张 | 现金 7~30 天固定支出 | 谨慎决策 |
| 危险 | 现金 < 7 天固定支出 | 警告，员工士气下降 |
| 断裂 | 现金 < 0 | 触发被动收缩（本版本简化为直接亏损） |
| 破产 | 连续 7 天负且无解 | 存档结束 |

## 三、经营系统

### 3.1 订单系统

| 类型 | 客单价 | 耗时 | 难度 | 解锁条件 |
|---|---|---|---|---|
| 证件照 | 低 | 短 | 低 | 初始 |
| 标准写真 | 中 | 中 | 中 | 初始 |
| 婚纱 | 高 | 长 | 高 | 新娘妆化妆师 |
| 亲子 | 中 | 长 | 中 | 儿童道具 |
| 宠物 | 中 | 中 | 高 | 宠物安抚道具 |
| 商业产品 | 高 | 中 | 中 | 商业摄影设备 |
| 网红打卡 | 低 | 短 | 低 | 网红场景 |
| 高端定制 | 极高 | 长 | 极高 | 口碑 4 星 + 大师设备 |

**订单流程**：咨询 → 报价 → 预约 → 到店 → 化妆 → 场景 → 灯光 → 拍摄 → 选片 → 修图 → 交付 → 售后

**排期规则**
- 每天有限时段（8 个），每个订单占 1~4 个时段；
- 超时接单 → 客人等待 → 满意度下降；
- 员工数量决定同时可处理的订单数。

### 3.2 定价系统

| 策略 | 价格系数 | 客流影响 | 口碑影响 |
|---|---|---|---|
| 低价引流 | 0.6x | +50% | − |
| 市场均价 | 1.0x | 基准 | 基准 |
| 中高端 | 1.5x | −30% | + |
| 高端定制 | 2.5x | −60% | ++ |
| 奢侈 | 4.0x | −80% | +++ |

**定价与品牌调性挂钩**：低价做久了，高端客人不来；高端做久了，大众客人不敢进。

### 3.3 广告与线上运营

| 渠道 | 成本/天 | 覆盖 | 转化率 | 品牌影响 |
|---|---|---|---|---|
| 社区传单 | 低 | 本地 | 低 | 亲民 |
| 朋友圈 | 低 | 熟人 | 中 | 亲民 |
| 小红书 | 中 | 年轻女性 | 中 | 网红 |
| 抖音 | 中 | 大众 | 高 | 网红 |
| 本地杂志 | 高 | 高端 | 低 | 专业 |
| 异业合作 | 中 | 精准 | 中 | 视对象 |

**线上账号**
| 指标 | 说明 |
|---|---|
| 粉丝数 | 影响自然客流和广告转化 |
| 内容表现 | 每条内容的曝光 / 互动 / 涨粉 |
| 发布频率 | 每天可发 1 条 |
| 内容来源 | 相册中的作品 |
| 内容评分 | 作品质量 × 话题度 × 时机 |

**线上 → 线下转化**：线上曝光 → 互动 → 涨粉 → 到店预约 → 线下消费

### 3.4 员工系统

| 岗位 | 作用 | 工资 |
|---|---|---|
| 摄影师 | 拍摄，决定质量上限 | 高 |
| 化妆师 | 妆造，影响上镜度和满意度 | 中 |
| 修图师 | 后期，影响交付速度和质量 | 中 |
| 客服 / 销售 | 接单、安抚、追加销售 | 低 |
| 助理 | 打杂，提升效率 | 低 |

**员工属性**：技能 / 速度 / 状态（疲劳、士气）/ 性格 / 忠诚

**员工管理**：招聘（花钱，看运气）、培训（花钱，提升技能）、排班、解雇（赔钱，掉士气）、加薪

**员工出错**
- 每多一个员工，每天多一次出错判定；
- 出错类型：迟到、拍废、说错话、丢东西、和客人吵架；
- 出错后果：差评、赔偿、重拍、口碑下降。

### 3.5 场地系统

**网格制**：初始 6×8 格，每格 0.5 米。

| 区域 | 作用 | 缺失后果 |
|---|---|---|
| 接待区 | 客服、等待、选片 | 客人站着等，满意度掉 |
| 化妆区 | 化妆师工位 | 化妆速度减半 |
| 棚拍区 | 拍摄主场地 | 接不了正经单 |
| 后期区 | 修图工位 | 修图效率低 |
| 储物区 | 放设备道具 | 设备损坏率上升 |
| 展示区 | 挂作品、样品 | 新客信任度低 |

**扩张**

| 方向 | 面积 | 购地费 | 装修费 | 工期 |
|---|---|---|---|---|
| 向右 | +2×8 | 中 | 中 | 2 天 |
| 向后 | +6×3 | 高 | 高 | 3 天 |
| 二楼 | +6×8 | 极高 | 极高 | 5 天 |

**扩张风险**：每月固定支出跳涨；施工期间营业效率下降；收入没跟上 → 亏损螺旋。

**收缩**
| 方式 | 触发 | 回收 |
|---|---|---|
| 主动收缩 | 玩家选择 | 投入的 30% |
| 被动收缩 | 现金断裂 | 废品价，装修全损 |

**装修**：从家具库拖拽到格子（每物件占 1~4 格）；成本 = 购买费 + 安装费 + 每日维护 + 拆除费；
氛围分影响客单价、员工效率、锐评好评率；**边际递减**——堆满奢侈品不如搭配得当。

### 3.6 设备系统

| 类别 | 影响 | 升级效果 |
|---|---|---|
| 机身 | 画质上限 | 解锁高分辨率订单 |
| 镜头 | 焦段 / 光圈 | 解锁虚化 / 广角订单 |
| 灯光 | 布光可能性 | 解锁复杂光影订单 |
| 背景 | 场景多样性 | 解锁主题订单 |
| 道具 | 拍摄辅助 | 解锁特殊订单 |
| 修图设备 | 后期效率 | 缩短交付时间 |
| AI 设备 | 自动化 | 降低人工成本，但影响品牌 |

**设备维护**：每日折旧；随机故障；维修费随设备价值上升。

## 四、微操系统

| 微操 | 触发 | 玩法 | 评分维度 |
|---|---|---|---|
| 拍摄 | 亲自拍摄订单 | 取景框平移/变焦、构图辅助线、"微笑峰值"窗口内按快门 | 构图 + 时机 + 清晰度 |
| 灯光 | 高价值订单或主动练习 | 2~4 个光源，各调角度/距离/功率/色温/柔光罩，实时预览 | 明暗比、重影、背景分离度 |
| 场景搭建 | 高价值订单或主动练习 | 道具库拖拽摆放，调整位置/角度 | 主题契合、构图友好、灯光协同 |
| 动作指导 | 拍摄过程中 | 客人有紧张度/疲劳度/信任度；从指令卡选话术 | 指导成功 → 微笑窗口变长 |
| 后期修图 | 交付前 | 滑块调曝光/色温/对比/磨皮 | 客人偏好；过度修图 → 满意度下降 |
| 外出采风 | 主动选择 | 随机场景、有限胶卷、移动目标、拍特定构图 | 收益：技能点、灵感、素材、稀有作品 |

**拍摄结果**：照片质量分 → 客人满意度、小费、口碑、复购。跳过微操按员工技能自动结算，无额外加成。

## 五、附属系统

### 5.1 吵架系统

**触发**：特定客诉场景。**玩法**：回合制论战，双方气势条；玩家从手牌选择回应。
**手牌类型**：讲事实、讲道理、打感情、耍无赖、认怂。

| 顾客类型 | 弱点 | 赢了后果 |
|---|---|---|
| 蛮横型 | 讲事实 | 灰溜溜走人 |
| 精明型 | 耍无赖 | 反而尊重你 |
| 情绪型 | 打感情 | 变死忠 |
| 网络型 | 讲道理 + 证据 | 删帖 |
| 碰瓷型 | 耍无赖对轰 | 拉黑 |
| 权力型 | 讲事实 + 合同 | 可能丢单 |
| AI 质疑型 | 真实价值 | 服气 |

| 结果 | 影响 |
|---|---|
| 赢 | 按原价付，口碑 +，品牌硬气 |
| 输 | 白嫖 / 砍价，口碑 −，碰瓷客变多 |
| 平 | 打折，口碑不变 |

**限制**：同一天最多吵 2 次；吵架消耗时间和精力；赢太多 → 品牌变凶 → 温柔客群流失。

### 5.2 锐评系统

**触发**：游戏内每周三晚。**玩法**：从相册选 1 张投稿，锐评师点评，结果分五档。

| 锐评师类型 | 风格 | 受众 |
|---|---|---|
| 毒舌老法师 | 专业刻薄 | 同行 |
| 抽象艺术人 | 高深莫测 | 艺术圈 |
| 沙雕网友 | 纯搞笑 | 大众 |
| 温柔鼓励型 | 少见好评 | 全客群 |
| 神秘 AI 评审 | 冷冰冰数据 | 极客 |

| 档位 | 粉丝 | 口碑 | 技能点 |
|---|---|---|---|
| 封神 | +++ | ++ | + |
| 好评 | ++ | + | + |
| 有梗 | ++++ | − | ++ |
| 毒舌 | ++ | −− | ++ |
| 无人问津 | 0 | 0 | 0 |

**联动**：客片被锐评 → 客人看到 → 复购或投诉；爆梗作品 → 可印海报、做周边；锐评被骂 → 可回怼 → 触发吵架。

### 5.3 客服与售后

| 事件 | 选项 | 影响 |
|---|---|---|
| 客人说照片显胖 | 免费重拍 / 部分退款 / 解释 | 金钱、口碑、客人情绪 |
| 要求加急 | 加钱 / 拒绝 / 加班 | 金钱、员工士气 |
| 要求免费加修 | 同意 / 拒绝 / 协商 | 口碑、利润 |
| 差评威胁 | 妥协 / 硬刚 / 协商 | 口碑、品牌 |
| 改期 | 同意 / 拒绝 / 收费 | 排期、满意度 |

**售后**：重拍（消耗时间、耗材）、退款（直接损失）、加急（员工加班、士气下降）、修图返工（修图师时间占用）。

### 5.4 品牌调性

| 调性 | 特征 | 客群 | 定价上限 |
|---|---|---|---|
| 亲民 | 便宜、快、热闹 | 大众 | 低 |
| 专业 | 设备好、流程严 | 同行 / 高端 | 高 |
| 艺术 | 氛围强、慢 | 藏家 / 文艺 | 极高 |
| 网红 | 打卡点、出片 | 年轻人 | 中 |
| 硬气 | 不妥协、有原则 | 讲理的高端客 | 高 |

**调性由行为累积决定**（玩家不能直接设定），影响：定价上限、广告渠道效果、锐评师态度、吵架时谁站你、员工招聘难度。

## 六、市场环境

### 6.1 AI 冲击

| 阶段 | AI 能做什么 | 市场影响 |
|---|---|---|
| 萌芽 | 证件照、简单修图 | 证件照利润减半 |
| 冲击 | 标准写真、换脸 | 中端写真订单 −30% |
| 碾压 | 婚纱、全家福 | 传统婚纱店倒闭 |
| 逼宫 | 艺术摄影 | 高端市场动摇 |
| 共存 | 接近专业 | 玩家选择路线 |

**AI 成本**：订阅费、算力费、版权费。用 AI 的店单张成本低，但每月固定支出高。

| AI 短板 | 玩家打法 |
|---|---|
| 没有真实情感 | 拍真实瞬间 |
| 没有现场 | 卖体验 |
| 没有实体 | 做相册、相框 |
| 没有信任 | 做老客、社区 |
| 没有故事 | 每张照片有故事 |
| 不会吵架 | 吵架赢 AI 店 |
| 不懂本地 | 做本地人情网络 |
| 有 AI 味 | 锐评师和客人反感 |

| 路线 | 短期 | 中期 | 长期 |
|---|---|---|---|
| 纯低价 | 有单 | 被卷死 | 必输 |
| 纯手工 | 单少但精 | 客群窄但稳 | 小但活 |
| 纯 AI | 效率高 | 利润薄 | 被更便宜 AI 卷 |
| 真人 + AI | 成本高 | 质量高 | 建立壁垒 |
| 转型体验 | 收入降 | 新客群 | 不可替代 |

**核心不等式**：`不可替代度 > AI 替代能力 → 活得好`；反之被卷。

### 6.2 竞争对手

| 对手 | 特征 | 可做的事 |
|---|---|---|
| AI 照相馆 | 价格砍半、出片快、没有真实体验 | 探店、攻击、合作 |
| 传统照相馆 | 老牌口碑稳、设备旧创新慢 | 可能挖你员工 |
| 网红工作室 | 线上强线下弱、流量大交付差 | 可能抄袭你风格 |

### 6.3 随机事件表

| 事件 | 效果 | 持续 |
|---|---|---|
| 隔壁开新店 | 客流 −20% | N 天 |
| 网红探店 | 客流 +50% | N 天 |
| 相机故障 | 拍摄效率 −50% | 维修后 |
| 员工请假 | 产能 −1 人 | N 天 |
| AI 平台降价 | 低端订单利润 −30% | 永久 |
| 房东涨租 | 固定支出 +10% | 永久 |
| 老客户介绍 | 新客 +N | 一次性 |
| 锐评封神 | 粉丝 +N，客流 +N | N 天 |
| 锐评翻车 | 口碑 −N，客流 −N | N 天 |
| 天气异常 | 外拍效率变化 | N 天 |
| 停电 | 当天无法营业 | 1 天 |
| 相机摔了 | 维修费 + 停机 | N 天 |
| 客人带一家人来 | 订单超载 | 1 天 |
| 隔壁抄袭 | 客流 −10% | N 天 |
| 平台算法变化 | 线上曝光 −50% | N 天 |
| 员工被挖 | 离职风险 + | 永久 |
| 版权投诉 | 赔偿 + 下架 | 一次性 |
| 热搜事件 | 客流暴增或暴跌 | N 天 |

## 七、经营问题库

| 类别 | 问题 | 玩家选择 |
|---|---|---|

## 九、UI 与反馈

- **主界面**：店面俯视图（网格）；顶部现金 / 日期 / 时间 / 速度控制；左侧预约列表与员工状态；右侧线上账号数据与事件通知；底部操作按钮（接单、采购、招聘、装修、发内容）。
- **日报表**：
  ```
  日期：第 47 天
  收入：+1,240
  固定支出：-680
  变动支出：-320
  净现金流：+240
  现金余额：3,450
  口碑：3.2 星
  粉丝：1,240
  ```
- **反馈原则**：所有数值变化即时可见；现金流为负时屏幕边缘红色脉冲；员工状态用表情图标；客人满意度用星级；线上数据用图表；**事件用弹窗，必须处理才能继续**。

## 十、本版本实现范围（MVP）

### 10.1 已实现

| 系统 | 实现程度 |
|---|---|
| 现金流 | 收入 / 固定支出 / 变动支出 / 日报表 / 现金流四态 / 破产结算 — **完整** |
| 订单 | 8 种订单类型全量目录；预约池 → 接单 → 拍摄 → 交付全流程；排期与逾期 |
| 定价 | 5 档定价，系数 / 客流 / 口碑 / 品牌推力全部生效；高定价会改变到店订单类型 |
| 员工 | 5 岗位；招聘 / 培训 / 解雇；每天出错判定与离职风险；工资计入固定支出 |
| 场地 | 6×8 网格 + **向右扩店一次**；分区与设备共 13 项，等级 1~5 |
| 拍摄微操 | 构图 + 时机 + 清晰度三轴 → 质量分；跳过微操按员工技能自动结算 |
| 吵架 | 5 张手牌（含认怂）× 7 类顾客；气势条回合制；每天上限 2 次；输赢平三种后果 |
| 锐评 | 每周三投稿；5 类锐评师 × 5 档结果；粉丝 / 口碑 / 技能点联动 |
| 线上账号 | 6 个广告渠道；每天发 1 条内容；粉丝自然增长与线上→线下转化 |
| AI 冲击 | 5 阶段时间线；AI 订阅成本；**不可替代度 vs 替代能力**每日结算 |
| 随机事件 | 18 个事件（含永久倍率 / 持续 N 天 / 一次性三类效果） |
| 客服售后 | 5 类客服事件 × 3 选项，模态拦截（不处理无法继续） |
| 品牌调性 | 由行为累积积分决定，5 种调性 |
